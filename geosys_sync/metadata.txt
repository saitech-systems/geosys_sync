about=Directional sync against the GeosysAI /api/qgis/v1 API. Pull server datasets into QGIS (vector GeoPackage, raster COG GeoTIFF) with styling; push QGIS layers back, creating new datasets or overwriting previously synced ones. Rasters are converted to Cloud Optimized GeoTIFF locally and uploaded directly to object storage, and single-band raster classes sync as a Paletted / Unique values renderer. Requires a GeosysAI platform account whose organization has QGIS sync enabled; the plugin does nothing without a GeosysAI server.
